# Портативные сборки Folder Access Review

Папки `1.0` … `1.5` содержат self-contained `FolderAccessReview.exe` (или более ранние имена exe в 1.0–1.2).

Эти каталоги **тяжёлые** (~170 MB каждая) и по умолчанию **не коммитятся** в git (см. `.gitignore`). Собирайте локально или берите установщик из `installer\` после `.\setup\build-installer.ps1`.

## Функционал по версиям

| Версия | Кратко |
|--------|--------|
| **1.0** | MVP: глубина, только явные ACE, фильтры, экспорт |
| **1.1** | + унаследованные ACE и фильтр наследования |
| **1.2** | + участники групп AD |
| **1.3** | + каталоги субъекта по всему скану (◆) |
| **1.4** | + вкладка «Пользователи», SQLite прямых ACE |
| **1.5** | + выбор папки базы (в т.ч. общая ProgramData) |

Подробности — в корневом [README.md](../README.md).
