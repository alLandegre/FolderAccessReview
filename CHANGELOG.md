# Changelog

Все значимые изменения **Folder Access Review**.

## [1.5.0] — 2026-07-30

### Добавлено
- Выбор папки SQLite-базы на вкладке «Пользователи» (Обзор / ProgramData / По умолчанию)
- Сохранение пути в `settings.json` для каждой Windows-учётки
- Рекомендуемый общий каталог: `C:\ProgramData\Folder Access Review`

## [1.4.0] — 2026-07-30

### Добавлено
- Вкладка «Пользователи» и SQLite-база прямых ACE пользователей
- Поиск забытых персональных назначений по пользователю
- Пометка «Не найдено в последнем скане» при повторном обходе

## [1.3.0] — 2026-07-29

### Добавлено
- Список каталогов текущего скана для выбранного субъекта
- Навигация к папке и метка ◆ в дереве

## [1.2.0] — 2026-07-29

### Добавлено
- Участники групп безопасности из Active Directory
- Раскрытие вложенных групп

## [1.1.0] — 2026-07-29

### Добавлено
- Отображение унаследованных ACE
- Фильтр наследования

### Исправлено
- Исправление сценария, когда на вложенной папке права только унаследованы

## [1.0.0] — 2026-07-29

### Добавлено
- MVP: сканирование с глубиной, явные ACE, фильтры, экспорт CSV/XLSX
- Self-contained publish и Inno Setup (позднее)
